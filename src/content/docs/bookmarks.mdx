title: Bookmarks

Bookmarks are [text objects](/jjui/revisions/text-objects) on the revisions they point to, so every bookmark action works on the focused bookmark. The bookmarks view is the Revisions view with a revset that lists bookmarks, and a quick inline input sets bookmarks on a revision.

## Bookmarks view

{/* TODO: screenshot */}

Press `b` to open the bookmarks view. The revset becomes `bookmarks() | remote_bookmarks()` and the cursor lands on a bookmark. A bookmarks bar under the revset line shows the available remotes and the current name filter.

| Key | Action |
|-----|--------|
| `tab` / `shift+tab` | Next / previous remote. Selecting `origin` sets the revset to `remote_bookmarks(remote=exact:"origin")` |
| `/` | Filter bookmarks by name (`enter` applies, `esc` cancels) |
| `k` / `up` at the top of the log | Focus the remotes line (see [Remotes](/jjui/git)) |
| `esc` | Leave the bookmarks view and restore the previous revset |

The bar starts with `all` and `local` entries, followed by each configured remote.

## Bookmark actions

With a bookmark focused (`h`/`l` to move between objects, or `ib` to jump to one), these keys are available:

| Key | Action |
|-----|--------|
| `r` | Rename the bookmark in place |
| `m` | Move the bookmark to a target revision. The target prompt tells you when the move goes backwards or sideways |
| `a` | Advance the bookmark (`jj bookmark advance`) |
| `t` / `T` | Track / untrack. Only the applicable action is offered |
| `G` | Push the bookmark |
| `F` | Fetch just this bookmark |
| `x` | Delete the bookmark |
| `X` | Forget the bookmark |
| `d` | Show the diff of the whole branch since its fork point |
| `C` | Annotate: review the branch |

Deleting does not ask for confirmation.

Press `space` to check the focused bookmark and jump to the next one. Actions then apply to all checked bookmarks. Checked objects are highlighted in place.

Press `*` on a bookmark to narrow the revset to its branch. See [Text objects](/jjui/revisions/text-objects).

## Setting a bookmark

Press `shift+b` on a revision to open an inline input box next to the revision's existing bookmarks.

- Type a new name to create a bookmark on that revision.
- Type the name of an existing bookmark to move it to that revision.
- You can repeat this to create multiple bookmarks on the same revision.

Autocomplete candidates are ranked by log distance, so bookmarks closest to the revision come first.

See [Remotes](/jjui/git) for fetching and pushing.
