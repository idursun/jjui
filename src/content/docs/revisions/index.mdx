Revisions is the default view in `jjui`. Other views (Oplog, Diff) are stacked on top of it — pressing `esc` from any of them returns here. The bookmarks and remotes views are this same view with a different revset.

## Core navigation

- `j`/`k` or arrows: move
- `pgup`/`pgdown`: page navigation
- `home`: jump to the first revision
- `end`: jump to the last revision
- `@`: jump to working copy
- `f`: [Ace Jump](/jjui/ace-jump)
- `shift+j`: jump to parent
- `shift+k`: jump to children
- `space`: check the focused object and move to the next one

The navigation keys (`j`/`k`, `pgup`/`pgdown`, `home`/`end`, `@`, `f`) live in a shared `revisions.nav` scope, so they work the same in the revisions view and in every operation (rebase, squash, abandon and so on).

## Text objects

The cursor can move inside the selected revision onto its change id, bookmarks, tags, author and more. See [Text Objects](/jjui/revisions/text-objects) for the full guide.

- `h`/`l` or `left`/`right`: previous/next object on the revision
- `0`: back to the revision itself
- `i` followed by a letter: jump to a kind (`ib` bookmark, `it` tag, `id` description, `ia` author, `is` timestamp, `ii` change id, `ic` commit id, `ix` conflict, `iv` divergent, `iw` workspace, `ie` elided)
- `*`: narrow the revset to the focused object

## Selection

The highlighted revision is the default source for all operations. `space` checks the focused object (a revision, a bookmark, a change id and so on) and moves to the next object of the same kind. Operations that support multi-select will use all checked objects. Checked objects are highlighted in place.

When you press `n` with multiple revisions selected, they become the new revision's parents in the order you selected them. Select the revision you want as the first parent first; parent order matters when the merge is pushed to Git.

- Select multiple revisions then press `r` → all selected become the rebase source.
- Select multiple revisions then press `a` → abandon applies to all of them.
- Check bookmarks then press `shift+g` → push all of them. Check change ids then press `shift+g` → push those changes.
- `esc` clears the current selection.

### Mouse selection

- Click: move cursor
- Ctrl+click: toggle-select a revision
- Alt+click: range-select from the previous cursor position to the clicked revision

## Main actions

- `j` on a focused change id: open [Details](/jjui/details)
- `d`: open full diff
- `alt+d`: compare two revisions with [Diff Range](/jjui/diff-viewer#diff-range)
- `enter`: [Inline Describe](/jjui/revisions/inline-describe)
- `shift+d`: describe in editor
- `shift+c`: open the experimental [Annotation View](/jjui/revisions/annotation)
- `n`: create new change from the highlighted revision (or from all selected revisions)
- `s`: split
- `alt+s`: split parallel
- `e`: edit
- `alt+e`: force edit
- `shift+e`: diff edit
- `c`: commit
- `shift+b`: set bookmark
- `shift+t`: set tag
- `shift+n`: add workspace

## Creating a revision at a specific position

`n` creates a new revision as a child of the selected revisions, or the highlighted revision when nothing is selected. To place it elsewhere, create it first then rebase it into position:

1. Press `n` to create the revision.
2. Navigate to the new revision.
3. Press `r` to enter rebase mode.
4. Navigate to the target and press `a` (after) or `b` (before), then `enter`.

## Revision operations

- `r`: [Rebase](/jjui/revisions/rebase)
- `shift+s`: [Squash](/jjui/revisions/squash)
- `shift+a`: [Absorb](/jjui/revisions/absorb)
- `a`: [Abandon](/jjui/revisions/abandon)
- `y`: [Duplicate](/jjui/revisions/duplicate)
- `shift+r`: [Revert](/jjui/revisions/revert)
- `shift+m`: [Set Parents](/jjui/revisions/set-parents)
- `v`: [Evolog](/jjui/revisions/evolog)

## Other views and tools

- `shift+l`: edit [Revset](/jjui/revset) with autocomplete
- `b`: [Bookmarks](/jjui/bookmarks) view
- `g`: [Remotes](/jjui/git) line (fetch and push)
- `o`: [Oplog](/jjui/oplog)
- `u`: [Undo](/jjui/undo-redo)
- `shift+u`: [Redo](/jjui/undo-redo)
- `shift+w`: [Command History](/jjui/command-history)
- `ctrl+t`: [Fuzzy File Finder](/jjui/fuzzy-file-finder)
- `f`: [Ace Jump](/jjui/ace-jump)

## Search, preview, and exec

- `/`: start quick search
- `'`: next match
- `"`: previous match
- `esc`: clear quick search
- `p`: toggle [Preview](/jjui/preview)
- `shift+p`: move preview to bottom
- `:`: execute `jj` command
- `$`: execute shell command
- `ctrl+r`: refresh revisions

All default bindings are defined in `internal/config/default/bindings.toml` in the source repository.
