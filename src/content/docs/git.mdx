Press `g` to open the remotes line. It opens the [bookmarks view](/jjui/bookmarks) with the cursor on the line of remotes under the revset.

## Remote objects

Each configured remote is an object on the line, preceded by `all` and `local` entries. Moving between them changes the revset (`all` shows local and remote bookmarks, `local` only local ones, a remote only that remote's bookmarks) and the preview, which shows that remote's bookmarks or, for `all`, the output of `jj git remote list`. You can also click an entry.

## Keys

| Key | Action |
|-----|--------|
| `h` / `l` or arrows | Previous / next remote |
| `j` / `down` | Back to the log |
| `f` | Fetch |
| `t` | Fetch tracked |
| `p` | Push |
| `P` | Push tracked |
| `d` | Push deleted |
| `D` | Push all and deleted |
| `r` | Rename the remote (`enter` applies, `esc` cancels) |
| `x` | Remove the remote (asks for confirmation) |

## Per-bookmark and per-change pushes

The old Git menu commands for single bookmarks and changes now live on the things themselves:

- `G` on a focused bookmark pushes it, and `F` fetches just that bookmark.
- `G` on a focused change id pushes the change (`jj git push --change`).

See [Bookmarks](/jjui/bookmarks) and [Text objects](/jjui/revisions/text-objects).

## Credential prompts

When a command started by jjui needs Git or SSH credentials, jjui can show the
askpass prompt inside the application instead of letting the subprocess take
over the terminal. Usernames are shown normally; passwords and passphrases are
masked. The command status is hidden while the prompt is open.

This is enabled by default. To use your own credential or SSH prompt instead,
disable it in `config.toml`:

```toml
[askpass]
enabled = false
```

Askpass prompts are not available on Windows. jjui starts normally and the
setting is ignored there.
