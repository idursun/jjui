Press `p` to toggle the preview pane. It updates automatically as you navigate — what it shows depends on what is currently selected.

![GIF](/jjui/gifs/jjui_preview.gif)

## Context-aware content

The preview follows the focused object. Press `h`/`l` on a revision to move between its objects, and the preview changes with them. Kinds without their own command fall back to `node`.

| Focused object | What preview shows |
|----------------|--------------------|
| Revision (`node`) | Diff of that revision (`jj show`) |
| Description | The full description (`jj log -T description`) |
| Bookmark | Diff of the branch since its fork point (`jj diff`) |
| Conflicted bookmark | The bookmark's targets (`jj bookmark list`) |
| Conflict | Conflicted paths (`jj resolve --list`) |
| Workspace | The workspace root (`jj workspace root`) |
| File in details | Diff of that file (`jj diff`) |
| Evolog entry | Patch diff of that entry (`jj evolog -p -n 1`) |
| Oplog entry | Operation details (`jj op show`) |
| Remote on the remotes line | That remote's bookmarks (`jj bookmark list --remote`) |
| `all` on the remotes line | Configured remotes (`jj git remote list`) |
| `local` on the remotes line | Local bookmarks (`jj bookmark list`) |

Change ID, commit ID, author, timestamp, tag, divergent and elided objects use the `node` command.

## Keys

- `p`: toggle preview on/off
- `shift+p`: move preview to bottom (toggle between side and bottom)
- `ctrl+n`: scroll one line down
- `ctrl+p`: scroll one line up
- `ctrl+d`: scroll half page down
- `ctrl+u`: scroll half page up
- `ctrl+h`: expand preview width
- `ctrl+l`: shrink preview width

When mouse support is available, you can scroll the preview and drag the separator to resize it.

## Full size preview

`jjui.ui.preview.set_size(percent)` sets the preview size and opens it if it is hidden. Unlike expanding or dragging the separator, it accepts `100`, so the preview can take the full screen. `jjui.ui.preview.size()` returns the current size.

This action toggles a full size preview with `alt+p`:

```toml
[[actions]]
name = "toggle preview full size"
lua = '''
if jjui.ui.preview.size() == 100 then
  jjui.ui.preview.set_size(50)
else
  jjui.ui.preview.set_size(100)
end
'''
key = "alt+p"
scope = "ui"
desc = "Toggle preview full size"
```

## Position

```toml
[preview]
position = "auto"      # auto | right | bottom
show_at_start = false
width_percentage = 50.0
width_increment_percentage = 5.0
```

- `auto` (default): uses bottom in tall terminals, right in wide terminals
- `right`: always on the right
- `bottom`: always at the bottom

## Customizing preview commands

Each kind of object has its own `[preview.object.<kind>]` table with a `command`: the arguments passed to `jj`. These are the defaults:

```toml
[preview.object.node]
command = ["show", "--color", "always", "-r", "$object.change_id"]

[preview.object.description]
command = ["log", "--color", "always", "-r", "$object.change_id", "--no-graph", "-T", "description"]

[preview.object.bookmark]
command = ["diff", "--color", "always", "--from", "fork_point(trunk() | $object.value)", "--to", "$object.value"]

[preview.object.conflicted_bookmark]
command = ["bookmark", "list", "--color", "always", "$object.value"]

[preview.object.conflict]
command = ["resolve", "--color", "always", "--list", "-r", "$object.change_id"]

[preview.object.file]
command = ["diff", "--color", "always", "-r", "$object.change_id", "$object.value"]

[preview.object.operation]
command = ["op", "show", "$object.value", "--color", "always"]

[preview.object.evolog]
command = ["evolog", "--color", "always", "-r", "$object.value", "-p", "-n", "1"]

[preview.object.remote]
command = ["bookmark", "list", "--color", "always", "--remote", "$object.value"]

[preview.object.remote_all]
command = ["git", "remote", "list"]

[preview.object.remote_local]
command = ["bookmark", "list", "--color", "always"]

[preview.object.workspace]
command = ["workspace", "root", "--color", "always", "--name", "$object.value"]
```

An object kind without a table falls back to `node`. You only need to write the tables you want to change. For example, to show a bookmark's own revision instead of the whole branch:

```toml
[preview.object.bookmark]
command = ["show", "--color", "always", "-r", "$object.value"]
```

Placeholders substituted at runtime:

- `$object.value`: the focused object's value (a bookmark name, file path, operation ID, and so on)
- `$object.change_id`: change ID of the revision the object is on
- `$object.commit_id`: commit ID of the revision the object is on
- `$revset`: the current revset expression
- `$preview_width`: the width of the preview pane

Refreshing (for example after a command changes the repo) re-runs the preview command.

Preview commands are run with `COLUMNS` and `LINES` set to the current preview pane size. `jjui` also sets `DFT_WIDTH` for difftastic-based previews so they wrap to the preview pane width automatically.
